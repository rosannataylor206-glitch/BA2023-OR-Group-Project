## 七条可组合路径

- A 任务损失 → 经验风险 → 正则罚 → 梯度/Hessian 与凸性 → 求解精度 → 外折泛化。Ridge 用 SVD 解释收缩，小 λ 路径的外推失配见迁移一。
- B 矩阵 → 谱分解/SVD → PCA 截断 → 所选距离空间 → 分群 → 跨重抽样稳定性。以外部变量验群体含义。
- C 分布 → 似然 → 参数及后验 → 参数和观测两种不确定性 → 概率预测 → 预期效用。比较 Brier/Log loss、覆盖与真实成本。
- D 几何间隔 → hinge → 不等式约束 → 拉格朗日/KKT → 对偶 Gram 矩阵 → 核。核矩阵及 α 上界回查可行性，代价阈值另外选择。
- E 可用数据 → 预测 → 条件情景 → 目标和约束 → 求解 → 留出策略成本。迁移四给出预测误差与行动代价反序。
- F 参数重抽 → Monte Carlo 保留协方差 → 情景 → 扰动 → 尾部风险 → 名次/决策稳定性。标参数风险和未来冲击，独立校准情景。
- G 状态 → 目标搜索 → 可采纳启发式 → DP → Bellman 方程 → MDP → 策略和资源边界。用可穷举小实例检查转移与最优性。

## 模型选择矩阵

| 数据与目标 | 基准及机制候选 | 成立条件与资源 | 验证和图形 | 历史用法与可验证改进 |
|---|---|---|---|---|
| 小样本连续响应，系数和预测 | OLS/QR，Ridge，分层或 GAM | 外生性或明确预测目标，SVD 排查秩，样条有效自由度受控 | 留组与折内调参，系数区间、残差与分布漂移 | HB07/11，按真实样本单位报告秩与外推 |
| 多周期时间序列或面板 | 持续值/季节朴素、AR/ETS、动态共享参数 | 频率、周期、horizon，跨国面板留组和时间区分 | 滚动 RMSE、误差相关、区间覆盖率，预测线与带 | HB07/08/11，情景同步传播外生变量不确定性 |
| 多类别或图像 | 类频、LDA、非线性 SVM、树或迁移表征 | 类支持、组依赖、标签质量、显存预算 | 留域 PR、校准和错例，明确训练算力 | HB05/08/09，按来源分组比较特征和网络 |
| 高维连续/混合特征，群体异质 | 原尺度分布、PCA、GMM/DBSCAN、层次 | 量纲、距离、非球形/变密度、缺失机制 | 子空间、重抽归属、外部效度图 | HB04 将簇压缩用于优化，回验聚合解可行 |
| 空间相关、区位外推 | 区域均值、空间协方差/分块 GAM | 距离与设施分布，部署距离，位置可用性 | 空间块和缓冲、误差地图 | HB06/10 场图规则，实测数据支持时核验证据 |
| 连续约束或整数调度 | 凸 QP/LP、SLSQP、MILP、非凸全局界 | 光滑性、约束资格、计算预算、整数性 | 残差、gap、KKT 与成本/可行域图 | HB04 比较降维代价和原空间回填 |
| 多指标偏好/效率 | 固定尺度加权、AHP、DEA、Pareto | 可补偿假设、参照组、不可行规则先判 | 排名扰动、逆转、效率松弛、可行前沿 | HB02 权重与实际资源输出并列 |
| 需求风险与行动 | 均值策略、条件分位数、情景规划/CVaR | 信息时点、成本非对称、概率与资源耦合 | 配对留出成本、尾部、约束敏感性 | HB07 需建立预测到博弈可量化接口 |
| 顺序决策且状态信息不全 | 规则策略、DP/MDP、信念状态 | 状态充分性、数据覆盖、计算状态规模 | Bellman 残差、模拟回报与部署反事实 | 先以小实例校验，再检验复杂策略的增值 |
