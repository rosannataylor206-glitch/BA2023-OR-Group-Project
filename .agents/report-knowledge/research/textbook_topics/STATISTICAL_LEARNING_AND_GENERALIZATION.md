## 问题与风险

设训练数据 D={(Xᵢ,Yᵢ)}，目标部署分布 P，预测规则 f，风险 R(f)=E_P[L(Y,f(X))]，经验风险 Rₙ=n⁻¹ΣL(Yᵢ,f(Xᵢ))。固定 f 且抽样符合 P 时 Rₙ 无偏估计 R，算法用同一 D 挑选 f 后，此结论不能直接套用。ERM 最小化 Rₙ，正则化最小化 Rₙ+λΩ(f)，测试风险估计须用未参与学习或选型的样本，且目标分布与评估设计对齐。分布漂移时报告目标人群及时间段。

连续 Y 写成 Y=m(X)+ε，m=E[Y|X]，E[ε|X]=0。分类对应条件概率 pₖ(X)=P(Y=k|X)。平方、绝对、pinball、交叉熵分别学习均值、中位数、分位数、概率，详见知识卡。预测追求新观测损失，推断还需明确估计目标、抽样过程和置信程序。参数模型预设有限维结构，非参数模型容量可随样本变化，两者都需要控制有效复杂度。

## 平方误差分解

固定 x，令独立测试响应 Y*=m(x)+ε*，η(x)=E_D[f̂_D(x)]。写 Y*−f̂_D(x)=ε*+[m(x)−η(x)]+[η(x)−f̂_D(x)]。三项交叉乘积期望为零，因测试噪声在给定 x 时与训练过程独立且均值为零，训练偏离也以 η 为中心。故条件风险为 Var(Y*|x)+(η−m)²+Var_D(f̂_D(x))。前项是在现有信息集下的不可约方差，后两项可通过模型与数据改善。需有有限二阶矩，条件异方差允许存在，分类零一损失不可照搬此恒等式。欠拟合表现为稳定但系统偏离，过拟合可表现为训练好、重采样预测波动大。U 形只是某些模型与采样设置的现象，插值附近可出现双下降，见 §10.8。验证见 examples/verify_statistical_learning.py 的恒等式检验。

## 验证决策树

1. 未来部署？按预测起点滚动或扩展训练窗，复现预测 horizon，最终保留最晚一段。标签覆盖跨界时加入 gap。面板预测已见实体用时间切分，预测新实体再隔离实体，必要时同时阻隔群组和时间。
2. 同人、同设备或站点反复出现？按部署的新个体或新群组留组。空间外推用空间块和缓冲带，距离尺度从相关结构及部署距离确定。
3. 近似 IID？数据充分可一次 holdout。小样本可 K-fold，多次随机重分仅反映切分波动，各折有训练重叠。LOOCV 每次训练 n−1 个样本，线性模型可用 eᵢ/(1−hᵢᵢ) 化简，前提是固定拟合流程及相应设计满秩。极端不平衡时保持可评估的分层。
4. 调参和报告同时发生？内层选特征、模型、阈值及超参，外层估泛化。各折内拟合插补、标准化、特征选择和校准；目标编码还须训练内交叉拟合。模型比较用配对外层损失，并依据预测单位估不确定性。
5. 估统计量波动？IID 情况用有放回样本 bootstrap，时序用块、群组依赖按群组重抽，配对比较保留配对。必须区分参数置信区间与新观测预测区间。单折指标或普通 bootstrap 不能修复不代表部署分布的问题。

## 指标与目标

令 eᵢ=yᵢ−ŷᵢ，pᵢ 为阳性预测概率。二分类四格 TP、TN、FP、FN 取固定阈值。样本汇总默认每个观测等权，面板和不平衡任务报告宏/微汇总口径。

| 指标 | 公式与优化 | 对应目标与边界 |
|---|---|---|
| MAE | mean(abs(e)) ↓ | 原量纲典型绝对偏离，相对平方损失弱化极端值，适合绝对成本 |
| MSE | mean(e²) ↓ | 大误差加重处罚，单位平方，点预测对应均值，极端点可支配 |
| RMSE | sqrt(MSE) ↓ | 原量纲的大误差代价，同一测试集排序等同 MSE，跨折先聚合平方误差 |
| R² | 1−Σe²/Σ(y−ȳ)² ↑ | 相对于测试集均值的误差改进，可负，常数响应分母为零，评估预测时另报可部署基准 |
| MAPE | 100 mean(abs(e/y)) ↓ | 相对误差，要求分母远离零，小实际值权重巨大，变号或零值应换指标 |
| Accuracy | (TP+TN)/n ↑ | 对错误同价的阈值分类，罕见正类时须对照多数类 |
| Precision | TP/(TP+FP) ↑ | 控制发现后的误报，随基率与阈值变化，无阳性预测时未定义 |
| Recall | TP/(TP+FN) ↑ | 漏报代价，预测全阳性亦可得 1，分母为零时未定义 |
| F1 | 2TP/(2TP+FP+FN) ↑ | 正类精召平衡，忽略 TN，多类别报告平均方式 |
| ROC-AUC | P(s₊>s₋)+0.5P(s₊=s₋) ↑ | 排序能力，须两类皆有，罕见事件下高分可伴随低精确率 |
| PR-AUC | ∫precision d recall ↑ | 罕见正类检索，基线随阳性率变。阶梯积分 AP 与梯形面积不同，明示口径 |
| Log loss | −mean(y log p+(1−y)log(1−p)) ↓ | 严格适当评分，极罚自信错误，零概率的真事件损失无穷，截断需披露 |
| Brier | mean((p−y)²) ↓ | 二元概率平方评分，同时受校准与区分影响，可配可靠性曲线 |

概率评分严格适当可由条件 Brier=p*(1−p*)+(p−p*)²，以及条件交叉熵=二元熵+KL 得到。若 FP/FN 代价分别 c_FP、c_FN，最小条件风险阈值为 c_FP/(c_FP+c_FN)，前提是概率已校准、代价固定且无资源耦合。有资源耦合时连接[预测到决策](OPTIMIZATION_THEORY.md#4-预测到决策)。竞赛中比较部署基准与有结构增益的高级候选，明写预期增益、反证实验及数据可用时点。
