# or-report-structure

先读[OR适配](../../report-knowledge/OR_ADAPTATION.md)；复用既有academic-writing-skills的四遍审阅和项目状态，不再建新任务管理系统。课程依据优先，真实Rubrics缺失时不造权重/Excellent结论。

用[结构合同](references/structure.md)连接原题→每问目标→模型/算法→可复现结果→表图→解释→局限→结论。先保留正确章节，缺读者功能才补，不固定IMRAD或竞赛目录。当前文件和正文问题从review/report_review_matrix.csv核验，不把历史状态搬入新候选。

assets/section_evidence.csv用于新增空白映射；不得把模板中的空行当已审阅。正式修改正文前提交有位置、A/B/C类别、优先级、证据和验收方法的计划；负责人由两人确认。
