# 按读者功能组织Report

先核验教师实际题目/Guidelines/Rubrics，再列每问的答案类型和必要证据。通常需要题名/摘要、背景与问题、数据/假设/符号、模型/方法、结果/讨论、验证/敏感性、管理启示、结论、参考文献及复现附录，但可以合并，不能用固定章节数替代回答问题。

每节登记：目的、主张、授权输入、输出/图表、解释范围、前后衔接、来源及未解决项。结果要回答“多少/与谁比较/为什么/在何条件下/采取什么行动”；方法节不能只列库名。先从结果反推摘要与结论，再从问题顺查到结果，两个方向都要闭合。

复用当前review/report_review_matrix.csv；若换候选DOCX，重新核对段落锚点和SHA，不沿用旧定位宣称复核。保持准确内容，P0/P1先处理，语言润色最后进行。两作者并行Word稿保留父提交和各自副本，人工合并。
