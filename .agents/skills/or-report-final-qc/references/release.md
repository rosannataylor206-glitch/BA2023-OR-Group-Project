# Report终检清单

冻结候选及源/结果/图表哈希；读取教师要求，缺失列出。确认所有原题任务有回答；公式/变量/单位/约束/结论同义；所有关键数字有精确结果路径和同一次运行的口径，不能拼接跨运行ID。检查参考文献元数据真实及对对应主张的支持、双向引用和表图编号连续。

PDF逐页检查目录、公式断行/编号、三线表/续页表头、题注与图同页、轴标签在最终尺寸可读、字体/字符/页眉页脚/白页/留白、书签和超链接；字体必须按实际PDF检查，不凭源码猜。PDF机器检查的边界/空文本只是待核信号，图片页不自动是缺页。

检查Word源的评论/修订/作者字段与公开边界，不自动删真实署名；源到PDF/Word转换失败不以截图冒充可编辑稿。准备提交前记录A/B/C问题闭合/披露、P0/P1处置、独立审核与人工作者确认。未实际执行的检查标NOT_RUN，缺依赖标BLOCKED，不能把基础设施样张PASS迁移为正式Report PASS。
