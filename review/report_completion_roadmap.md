# 双人Report完善路线图

负责人均待两人确认；不设建模手/编程手岗位。下列步骤围绕已有成果完善报告，重大模型/核心结果变化单独批准。

1. **身份与要求**：确认月球Report题名；取得BA2023教师原题、Guidelines、Rubrics、Syllabus/Slides和AI规则。179000t/年歧义单列待教师澄清。退出条件：权威版本可追溯。
2. **方法与证据**：按新版源码写闭式充分上界、有限目录、硬件增量、包装比例和LP验证；选择一个完整表图运行批次。退出条件：公式—代码—表图—主张一一映射。
3. **Q1–Q5分析**：保留已核对数值；补固定/重选份额、净/毛水量、敏感性范围、电网同约束对照和条件管理行动。按教师要求决定机构信位置。退出条件：每问有方法、结果、解释、局限。
4. **文稿结构**：按matrix消除错题封面、中文工作注、目录/公式/图表重号，补必要摘要/结论/附录；不为目录凑章节。退出条件：两个作者确认同一英文DOCX候选。
5. **交叉核对与终审**：逐个关键数字及参考文献核对；渲染最终DOCX检查分页/公式/图表，按真实Rubrics逐项评价；未解P0/P1不能建议提交。

Word协作：编辑前读取GitHub最新分支并登记Issue/文件版本；同时编辑时使用不同writer标识的副本和分支，记录父提交及SHA。禁止二进制自动合并/覆盖；两人手动合并后另存新候选，再执行数值和版式回归。组员应从GitHub固定commit获取资料，不以聊天压缩包作为隐含最新版。
