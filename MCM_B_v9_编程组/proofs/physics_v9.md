# v9 物理接口与分级质量账证明

## 1 研究对象与结论边界

我们使用圆形共面地月模型，地心段遵从二体引力，忽略月球有限影响球的进入和离开时间；所有推力简化为瞬时脉冲。地球顶端位于距地表100000公里处，随地球以角速度ω共转。月球以半径R的圆轨道运动。月面停车轨道高度为100公里。

这不是实际2050年航线，也没有解决真实月球轨道倾角、偏心率、太阳摄动、有限推力、空间站近接捕获、结构、热控与核安全。本节给的是这些简化条件内可复核的质量与时间接口。工程未知量不会因代码验证通过而变为已测事实。

v8只保留了“顶端刹车进入半椭圆”的一种地心段。v9把释放后的初始切向速度u作为有限目录参数：从刚好到达月球距离的半椭圆速度u_min，到顶端自由释放共转速度u_0=ωr_0。目录有21个速度点；此外有6个单因子工程情景。我们只比较这些点，不声称整个连续轨道设计的全局最优。

## 2 地心段与月球相对到达速度

令μ_E为地球引力参数，r_0为顶端距地心距离。释放后初始径向速度为0、切向速度为u。因此单位质量角动量与能量为

    h = r_0 u,
    ε = u²/2 − μ_E/r_0.

在月球轨道半径R处，守恒量给出

    v_t = h/R,
    v_r² = 2(ε + μ_E/R) − v_t².

只保留v_r²≥0的外向分支。月球圆轨道切向速度为v_M，故月球相对双曲超速的大小是

    v_∞ = sqrt(v_r² + (v_t − v_M)²).

这里必须做矢量相减，不能在有径向速度的自由释放情景下只减切向速度。

令p=h²/μ_E，e=p/r_0−1。初始点为近地点，月球距离处真近点角f满足

    cos f = (p/R − 1)/e.

地心段飞行时间是角动量积分

    τ = integral[0,f] { [p/(1+e cos θ)]² / h } dθ.

这同样适用于目录中的椭圆、抛物线边界附近与双曲线；不需要把自由释放误写成半椭圆飞行时间。

顶端速度匹配脉冲为|u_0−u|。月球100公里圆轨道半径为r_p，则月球捕获脉冲为

    Δv_cap = sqrt(v_∞² + 2μ_M/r_p) − sqrt(μ_M/r_p).

轨道拖船单程脉冲总和

    Δv_T = |u_0−u| + Δv_cap.

## 3 返程速度匹配与相位窗口

返程取同一条顺行地心圆锥曲线的入站分支：从真近点角−f开始，径向速度为−v_r、切向速度为v_t，到达近地点时径向速度为0、切向速度为u。再施加大小|u_0−u|的切向脉冲，与共转顶端速度匹配。自由释放端点u=u_0时，这个顶端脉冲为0。地心返程τ与出程相同；月球注入所需双曲超速大小与出程相同，所以相同Δv_cap可作为本对称模型的返程脉冲。

速度匹配并不足以证明空间交会，还必须检查位置和时刻。设顶端和月球初始经度为λ_A0、λ_M0，角速度为ω、n，释放时刻为t。出程交会条件为

    λ_A0 + ωt + f = λ_M0 + n(t+τ)  (mod 2π).

返程从月球出发时刻为s，顶端接回条件为

    λ_M0 + ns + f = λ_A0 + ω(s+τ)  (mod 2π).

两式关于出发时刻的相位变化率均为ω−n，因此任意请求时刻到下一次模型内对齐的等待严格小于

    T_phase = 2π/|ω−n|.

这只证明圆形共面模型中的相位可对齐，不是实际三维发射窗口。代码分别核对出程和返程方程，不能把“一天左右重复一次相位”当成所有现实轨道均每日可行。每窗口至多两班、港口服务、接收排队等能力在物流模块中另列。

## 4 轨道拖船与化学登陆器分离

净货按1吨归一化，χ_T、χ_L分别为轨道拖船和登陆器干重/净货。轨道拖船比冲I_T，登陆器比冲I_L，标准重力g_0；若速度单位为公里/秒，g_0也必须用公里/秒²。

    A_T = exp(Δv_T/(g_0 I_T)),  B_T=A_T,
    A_L = exp(Δv_L/(g_0 I_L)),  B_L=A_L.

Δv_L是从100公里月球轨道到表面的理想两脉冲量，再加每程明确声明的重力和操作损失裕量；默认加0.3公里/秒。该裕量不是实测损失。

从返程结束向前倒算：登陆器需以χ_L干重回到停车轨道，故表面起飞前需χ_L B_L。卸下1吨货物之前的触地质量为

    m_touch = 1 + χ_L B_L.

月球轨道分离前的登陆器湿重为

    M_L = A_L(1 + χ_L B_L).

拖船留在月球轨道；它返程要推送两套已卸货干结构，因此要保留返程推进剂

    P_Tr = (χ_T + χ_L)(B_T−1).

顶端出发总湿重与净货之比为

    β = A_T [M_L + χ_T + P_Tr].

所有月球往返推进剂从顶端一并携带，未假设免费的月面原位资源补给。登陆器的返程推进剂和拖船的返程推进剂分别记为

    P_Lr = χ_L(B_L−1),
    P_Tr = (χ_T+χ_L)(B_T−1).

顺序验算为

    β/A_T = M_L + χ_T + P_Tr,
    M_L/A_L = 1 + χ_L B_L,
    (M_L/A_L−1)/B_L = χ_L,
    (χ_T+P_Tr+χ_L)/B_T = χ_T+χ_L.

这条质量链没有把两种比冲求平均，也没有让核热拖船降落月面。

## 5 首次部署与后续提升量

每次正常返回后，χ=χ_T+χ_L的干结构留在顶端复用。因此无储存损失时，每次任务的新提升质量为(β−χ)倍净货；安装的每套干硬件另需首次提升χ倍其额定载货量。

如果整个储存期最多损失λ比例推进剂，则新提升质量系数为

    g = 1 + (β−χ−1)/(1−λ).

货物和干结构不按推进剂损失率蒸发。λ是总期损失上限，不是每日损失率。冷却、低温储箱和维持功率尚需真实指标；这个系数不能冒称完整热控工程已经得到验证。永久船损后的替换干结构必须另计，不能利用正常返程复用的公式免费补船。

## 6 默认值与时间口径

默认轨道拖船比冲900秒、化学登陆器450秒、两者干重/净货均0.2、每程月面裕量0.3公里/秒。这些是具名工程情景。NASA2019的一个核热概念给最大比冲900秒，能支持这个数字作为概念研究背景，不能证明本套载具已经存在。950秒敏感性点更不是该文献验证的性能。

27条目录中的两个默认端点为：

| 指标 | 半椭圆端点 | 共转自由释放端点 |
|---|---:|---:|
| 拖船每程总Δv 公里/秒 | 6.038063 | 5.899202 |
| 地心段时间 天 | 7.000836 | 0.575045 |
| 顶端湿重/净货 | 5.304977 | 5.198019 |
| 触地总重/净货 | 1.316544 | 1.316544 |
| 返回干重/净货 | 0.400000 | 0.400000 |
| 未计额外接收队列的就绪至触地预算 天 | 11 | 5 |
| 可与额外接收排队拼接的往返预算 天 | 32 | 20 |

就绪至触地预算包括地心段、理想月面转移段、一次相位等待、每程2天的遭遇操作裕量及0.5天轨道分离。触地后返程尾部包括第二次相位等待和遭遇裕量、返程理想飞行、3天表面操作、7天顶端操作以及0.5天会合。

必须直接对这个返程尾部取上界，不能用两个各自取整的上界相减。一般而言，ceil(C)−ceil(L)可能小于C−L。自由释放的未取整就绪至触地约4.15天，未取整完整周转约18.30天；19−5=14天不足以界住约14.15天的返程尾部。因此v9导出

    return_tail_upper_days = ceil(C_raw − L_raw) = 15,
    return_cycle_days = ceil(L_raw) + ceil(C_raw − L_raw) = 20.

未附加接收排队时，直接对全周转取整得到19天，另存于`return_cycle_direct_ceiling_days`；它不能拿来减去触地上界推算返程。若接收服务证明给完成交付上界M，物流层应以`M + return_tail_upper_days`作为回到顶端的上界，再追加备用激活等协议时间。这个20天接口比直接全周期取整稍保守，但能正确拼接接收排队。

目录21个名义速度点中，自由释放端点具有最小β。因此它被用作本次条件研究的默认接口；这不构成对连续所有轨道、三体转移或所有载具架构的最优性定理。

## 7 验证与实际证据

`physics_v9.py`执行以下检查并把具体残差写入`results/physics_v9.json`：

1. 27条分级质量链按实际燃烧顺序独立复算。
2. 每条任务的地心出程和返程分别用DOP853积分，共54次，核对位置、返回切向速度及能量守恒。
3. 每条任务在十年范围的33个请求日期分别核对出程、返程相位交会，共1782个方程。
4. 对全部27条任务分别检验出程整数上界、返程尾部整数上界及其相加后的周转接口，禁止通过独立上界相减构造尾部。
5. 拒绝零/负比冲、无效干重、负损失裕量、无效结构筛选和未支持的架构。

这些检查证明代码和声明的数学模型相符，不是月球实测航线验证。原始常数和概念背景分别查阅：

- JPL Astrodynamic Parameters，地月引力参数、日长和恒星日：<https://ssd.jpl.nasa.gov/astro_par.html>
- NASA 2019 Versatile Nuclear Thermal Propulsion：<https://ntrs.nasa.gov/citations/20190032556>
- Peet 2020 The Orbital Mechanics of Space Elevator Launch Systems：<https://arxiv.org/abs/2008.05244>。自由释放是架构背景，论文也提醒平面转换和相位覆盖限制；这里的月球轨道及质量数字是本项目推导。
