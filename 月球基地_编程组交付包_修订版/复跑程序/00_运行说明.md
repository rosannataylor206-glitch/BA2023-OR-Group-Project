# 编程组复跑说明

在 Python 3.12 虚拟环境中，进入本目录后依次执行以下命令。第一行安装本次验证使用的依赖版本。后续命令会重算主结果、导出论文结果表、生成图表，并运行两项补充分析。

```bash
python -m pip install numpy==2.3.5 scipy==1.17.0 matplotlib==3.10.8
python run_v9.py
python programming_handoff.py
python plot_handoff.py
python fault_attribution_v9.py
python joint_screening_v9.py
python joint_screening_v9.py --deadline-years 350 --emissions-cap-gt 1.99 2.81
```

份额选择的 LP 交叉核验单独运行（不属于主流程，也不改变任何主结果）：

```bash
python share_lp_check_v9.py
```

结果写入 `results/share_lp_check_v9.json`，其中给出决策变量、目标函数、约束、带单位的参数、LP 最优份额、解析份额、两者之差以及完整证书工期。该脚本只用于验证"解析平衡份额恰是所声明 LP 的最优解"，报告正文不得据此声称主流程使用了线性规划或单纯形法。

用下列命令重算同一限额下的低碳电网情景。将 `low_carbon_grid` 换成 `high_carbon_grid` 可得到高碳电网情景。命令示例为各情景指定单独的输出文件，以便与中央情景并列比较。

```bash
python joint_screening_v9.py --scenario low_carbon_grid --deadline-years 350 --emissions-cap-gt 2.81 --output results/supplemental/low_carbon_grid.csv
python joint_screening_v9.py --scenario high_carbon_grid --deadline-years 350 --emissions-cap-gt 2.81 --output results/supplemental/high_carbon_grid.csv
```

重算生成的结果位于本目录的 `results/` 和 `figures/`。报告引用可使用交付包外层的[结果表](../results/论文组结果表.csv)与对应图表。引用新一轮结果时，统一使用同一次运行的表、图和策略编号。
